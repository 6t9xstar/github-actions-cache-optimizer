# Changelog

All notable changes to this project are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-31

### Added

- First release of CachePilot: find GitHub Actions caches that never hit and print the optimized config.
- Output formats: text, JSON, SARIF 2.1.0, Markdown and GitHub Actions annotations.
- Reusable GitHub Action (`uses: 6t9xstar/github-actions-cache-optimizer@v1`).
